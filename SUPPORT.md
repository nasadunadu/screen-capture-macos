# Support

## Questions and help

Use GitHub Discussions when available. Otherwise, open an issue using the most relevant template.

Before asking for help:

1. Confirm that your Mac runs macOS 14 or later.
2. Check **System Settings → Privacy & Security → Screen & System Audio Recording**.
3. Relaunch Screen Capture after changing permission.
4. Try the latest published release.
5. Review the known limitations in the README.

Include the app version, macOS version, Mac model, and clear reproduction steps. Never attach an unredacted screenshot or log containing private information.

Security or privacy reports belong in the private process described in [SECURITY.md](SECURITY.md).
